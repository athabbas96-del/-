# Social media formats

Canvas sizes used by the social examples in every style, plus the main
platforms. Platform specs change often: check each platform's current help
pages before final export, and record the date you checked in the project brief.

| Format | Size (px) | Ratio | Text-safe area |
| --- | --- | --- | --- |
| Feed post, square | 1080 × 1080 | 1:1 | 60px margin all round |
| Feed post / ad, portrait | 1080 × 1350 | 4:5 | 60px margin; Instagram's profile grid shows a narrower 3:4 centre crop, so keep the key message in the middle |
| Instagram grid-native portrait | 1080 × 1440 | 3:4 | Matches the profile grid preview |
| Stories and Reels | 1080 × 1920 | 9:16 | Keep text out of the top 250px and bottom 340px |
| TikTok | 1080 × 1920 | 9:16 | Keep text out of the bottom ~400px and right ~140px (captions and buttons) |
| LinkedIn image post | 1200 × 1500 or 1080 × 1080 | 4:5 / 1:1 | 60px margin |
| LinkedIn document (carousel) | PDF, 1080 × 1350 pages | 4:5 | 60px margin |
| X image | 1600 × 900 | 16:9 | Centre 1200 × 675 for previews |
| YouTube thumbnail | 1280 × 720 | 16:9 | Keep the bottom-right corner clear (timestamp) |

## Export

- Images: PNG for graphics and text, high-quality JPEG for photos, sRGB.
- Video: H.264 MP4, 30fps, with captions (burned in or platform captions).
- Name files `brand_campaign_format_v01.ext`, for example
  `sprinklelab_dessertfirst_story_v01.mp4`.
