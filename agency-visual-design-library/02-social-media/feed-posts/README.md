# Feed posts

## 1. Anatomy

| Element | Rule |
| --- | --- |
| One message | One idea per post. If it needs two, make a carousel. |
| Headline | 3–8 words on the image; larger than you think (it is seen at about 350px wide on a phone) |
| Eyebrow | Optional: series name, date or category (Swiss "Insight 04", Pop "New flavour") |
| Visual | One hero image or one graphic device |
| Logo | Small and consistent in position; omit if the account avatar is enough |
| Safe margin | 60px on a 1080 canvas |

Test at phone size: shrink the post to 350px wide. If the headline is not
readable, it is too small or too long.

## 2. How each style builds a post

| Style | Post formula |
| --- | --- |
| Quiet Luxury | Product still, five words, centred small logo, no stickers |
| Swiss Precision | One number + source line, red square marker, LinkedIn first |
| Neo-Brutalism | Big statement + one outlined sticker + product shot |
| Organic Earth | Ingredient or field photo, blob frame, conversational line |
| Future Tech | Dark field, one metric or UI fragment, gradient word |
| Bold Editorial | Looks like a cover: kicker, huge serif quote, issue number |
| Playful Pop | Product cut-out on rotating brand colour, sticker for news |
| Clinical Clarity | One health tip, Mist background, icon, clear next step |
| Modern Heritage | Pattern frame, Arabic first, bilingual caption |
| Kinetic Sport | Skewed headline, one stat, action photo, speed stripes |

## 3. Templates

Build three to five templates per brand: announcement, quote, product, tip,
event. Lock the logo, grid, type styles and safe areas; leave the image and
copy editable. Keep templates in the design tool's shared library, and export a
"how to use" page with each.

## 4. Captions

- The first line carries the message; it shows before "more".
- Put any text that is in the image into the caption too (accessibility).
- Bilingual: Arabic first for Arabic-led brands, separated clearly from English.
- Hashtags: a few relevant ones, at the end.

## Checklist

- [ ] One message; headline readable at 350px wide
- [ ] Inside the 60px safe margin
- [ ] Built from a template; logo position consistent
- [ ] Image text repeated in caption; alt text added
