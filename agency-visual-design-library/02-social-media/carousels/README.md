# Carousels

Carousels earn the most attention when each slide gives a reason to swipe.

## 1. Structure

| Slide | Job |
| --- | --- |
| 1. Hook | A promise or a question: "3 signs it's time for a check-up" |
| 2–n. Content | One point per slide, same layout every time |
| n+1. Summary | The takeaway in one line |
| Last. Action | What to do next, with the brand |

Platforms allow many slides (Instagram allows up to 20 at the time of writing),
but 5–8 is usually enough.

## 2. Design rules

- Keep the grid, type positions and colours identical across slides. Change
  only the content.
- Number slides when the order matters (Swiss Precision numbers every slide).
- Use a continuous element that runs across slide edges (a line, a shape, a
  pattern band) to invite the swipe. Make sure each slide still works alone,
  because some platforms show slides individually.
- Language direction: swipes are always left to right on the platforms, but
  Arabic content inside each slide is RTL. Do not reverse slide order for Arabic.
- LinkedIn: upload carousels as a PDF document (4:5 pages).

## 3. Style notes

- Clinical Clarity: one health tip per slide, icon in a teal circle.
- Bold Editorial: slides read like turning pages: kicker, headline, pull quote.
- Neo-Brutalism: slides can look like app screens in outlined windows.
- Swiss Precision: numbered sequence, same grid, one red data point each.

## Checklist

- [ ] Hook slide promises something specific
- [ ] One point per slide; identical layout
- [ ] Each slide works alone
- [ ] Final slide has the action and the brand
