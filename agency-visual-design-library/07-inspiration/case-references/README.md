# Case references

Public work and books to study for each style. These are third-party works,
listed for learning. They are not agency work and must not be copied. Brand
work changes over time, so look at the current state before citing it in a
pitch.

| Style | Reference | What to study |
| --- | --- | --- |
| Swiss Precision | Josef Müller-Brockmann, *Grid Systems in Graphic Design* (1981) | Column and modular grid construction |
| Swiss Precision, Clinical Clarity | Unimark International (Massimo Vignelli, Bob Noorda), *New York City Transit Authority Graphics Standards Manual* (1970) | Systematic signage, one typeface, strict rules |
| Clinical Clarity | GOV.UK Design System (design-system.service.gov.uk) | Plain language, accessible components, form patterns |
| Clinical Clarity | NHS digital service manual (service-manual.nhs.uk) | Health content style, accessible patterns |
| Bold Editorial | Alexey Brodovitch's art direction of *Harper's Bazaar* (1934–1958) | Scale contrast, white space, type and photo as one composition |
| Bold Editorial, Quiet Luxury | Robert Bringhurst, *The Elements of Typographic Style* (1992) | Type detail, rhythm, proportion |
| Playful Pop | Mailchimp's 2018 rebrand by Collins | A bold colour, illustration and humour as a system |
| Kinetic Sport | Nike "Just Do It" (Wieden+Kennedy, 1988) | A short line that carries a whole sports brand |
| Modern Heritage | Louvre Abu Dhabi (Jean Nouvel, opened 2017) | Geometric pattern as architecture and light |
| Modern Heritage | Eric Broug, *Islamic Geometric Patterns* (2008) | Constructing star patterns on a grid |
| Modern Heritage, Arabic typography | Huda Smitshuijzen AbiFarès, *Arabic Typography: A Comprehensive Sourcebook* (2001) | Arabic script styles and modern Arabic type |
| Arabic typography | Khatt Foundation (khtt.net) | Arabic–Latin type design and bilingual practice |

To add a reference: name the work, the creator and year, and one line on what
to study. Do not add screenshots unless they are licensed.
