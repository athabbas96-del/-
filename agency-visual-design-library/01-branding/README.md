# Brand identity

How an identity is built, documented and applied. Every style in the library has
a *Brand applications* section (business cards, letterhead, application specs)
rendered on its style page; these guides explain the system behind them.

| Guide | Covers |
| --- | --- |
| [Logo systems](./logo-systems/README.md) | Logo variants, clear space, minimum size, misuse, file kit |
| [Identity systems](./identity-systems/README.md) | How logo, colour, type, imagery and graphic devices work as one system |
| [Brand guidelines](./brand-guidelines/README.md) | Structure and contents of a client brand book |
| [Stationery](./stationery/README.md) | Business cards, letterhead, envelopes, email signatures, print specs |

All brands named in examples are fictional sample brands from the visual library.
