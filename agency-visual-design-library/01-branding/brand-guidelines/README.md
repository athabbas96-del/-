# Brand guidelines

A brand book is a tool for the people who will apply the brand without us.
Write it for a junior designer at an external agency who has one afternoon.

## 1. Recommended structure

| # | Section | Contents |
| --- | --- | --- |
| 1 | Introduction | Purpose, audience, how to use the book, contacts for approvals |
| 2 | Brand platform | Positioning, values, personality, tone of voice with do/don't copy |
| 3 | Logo | Variants, construction, clear space, minimum sizes, colour versions, misuse |
| 4 | Colour | Palette with HEX, RGB, CMYK and spot values; roles and proportions; accessible pairings |
| 5 | Typography | Families and licences, scale, Arabic pairing, fallback fonts for Office and email |
| 6 | Imagery | Photography direction, shot examples, retouching rules, illustration if any |
| 7 | Graphic devices | Patterns, shapes, frames, icons; how and when to use each |
| 8 | Layout | Grids for key formats, safe zones, examples |
| 9 | Motion | Signature, durations, logo animation |
| 10 | Applications | Social, ads, web, presentations, stationery, signage, packaging, merchandise |
| 11 | Accessibility | Contrast pairs, minimum sizes, captioning, bilingual rules |
| 12 | Assets | Where to download logos, templates, fonts; file naming |

## 2. Writing rules

- Show, then tell: every rule has a correct example, and important rules have
  a "don't" example too.
- Give values, not adjectives: "clear space = height of the monogram", not
  "leave enough space".
- Keep the colour table complete: HEX for screen, CMYK for print, spot
  reference where used, and the approved text/background pairs.
- Include the Office reality: which fonts to use in PowerPoint and email when
  the brand fonts are not installed.
- Version and date the book; list what changed.

## 3. Format

Deliver a PDF for reading and printing, and keep a living web version (or a
Figma library) as the source of truth. Ship templates alongside: social
templates, a PowerPoint master, a Word letterhead and an email signature.

## 4. Using the library to start a book

Each style's generated spec in [`visual-styles/`](../../visual-styles/README.md)
already follows sections 3–10 for its fictional brand. Copy the relevant
style's spec as the skeleton and replace every sample value with the client's.

## Checklist

- [ ] All 12 sections present (or consciously omitted)
- [ ] Every rule has an example
- [ ] Colour values for screen, print and spot; approved pairs listed
- [ ] Office and email fallbacks defined
- [ ] Templates shipped with the book; version and date on the cover
