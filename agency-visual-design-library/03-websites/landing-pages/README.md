# Landing pages

A campaign landing page has one job: the action the ad promised.

## 1. Anatomy

| Block | Purpose |
| --- | --- |
| Hero | Repeats the ad's headline and image, so the visitor knows they are in the right place |
| Primary action | Visible without scrolling; repeated at the end |
| Benefits | Three to five, each a short heading and one sentence |
| Proof | Numbers, reviews, logos, certifications |
| How it works | Three steps |
| Objections | FAQ answering price, time, trust |
| Final action | Same action as the hero |

Remove the main navigation, or reduce it, so the page has no exits other than
the action.

## 2. Matching the campaign

The landing page continues the campaign: same style, same headline, same
image. Each style page's *Advertising campaign* section pairs a billboard and
display ads; their landing page should open with the same line, for example
"Ask your data anything." for the fictional Ortelia campaign.

## 3. Conversion rules

- One action; the button label repeats the promise ("Start free trial").
- Forms as short as possible; say what happens after submitting.
- Load fast: aim for Core Web Vitals "good" (LCP ≤ 2.5s, INP ≤ 200ms,
  CLS ≤ 0.1). Compress the hero image, set image dimensions to avoid layout
  shift, and avoid heavy third-party scripts.
- Track the action as a conversion and test one change at a time.

## 4. Legal and trust

Privacy notice and consent where data is collected; terms for offers; correct
disclaimers for regulated sectors (health, finance).

## Checklist

- [ ] Headline and image match the ad
- [ ] One action, visible above the fold and at the end
- [ ] Navigation removed or reduced
- [ ] Core Web Vitals in the "good" range
- [ ] Privacy and legal copy present
