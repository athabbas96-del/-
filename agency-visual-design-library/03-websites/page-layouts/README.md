# Page layouts

## 1. Core pages and their order of sections

| Page | Sections, top to bottom |
| --- | --- |
| Home | Hero (promise + primary action) → proof (logos, numbers) → offer (3–6 services or products) → featured work or product → testimonial → final call to action → footer |
| Services / product | Problem → solution → how it works (3–4 steps) → proof → pricing or enquiry → FAQ |
| Case study | Client and challenge → idea → work (big images) → results (numbers) → credits → next case |
| About | Story → people → values → locations → careers |
| Contact | Form (as few fields as possible) → direct details → map or locations → response time |
| Article | Kicker → headline → standfirst → body with pull quotes and images → author → related |

## 2. The hero

- One promise in 4–10 words, one supporting sentence, one primary action.
  A second action is allowed if it is clearly secondary.
- The library's heroes follow this: "Clear advice for complex decisions."
  (Swiss), "Care that listens." (Clinical), "Run the city." (Kinetic).
- Size the hero to its content, not to the full viewport, so the proof row is
  visible without scrolling on most laptops.

## 3. Proof

Numbers beat adjectives. Every style's website example has a proof row of
three facts (for example 80+ specialists, same-day appointments, JCI accredited).
Use real, sourced client numbers; the library's figures are samples.

## 4. Navigation

- 4–6 top-level items; the primary action as a button at the end.
- The logo links home. The current page is marked.
- Bilingual sites: a visible language switch in the header (Modern Heritage
  puts "EN" in the main navigation).
- On phones: a menu button with a visible label or an accessible name.

## 5. Footer

Contact details, secondary navigation, legal links (privacy, terms, cookies),
social links and the language switch.

## Checklist

- [ ] Each page follows a known structure; sections in a deliberate order
- [ ] Hero has one promise and one primary action
- [ ] Proof uses real, sourced numbers
- [ ] Navigation 4–6 items with a language switch where needed
