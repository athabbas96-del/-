# Foundations

The rules every style in the library is built on. Read these before adapting a
style for a client: they explain *why* the style specs look the way they do, and
how to keep a client adaptation correct.

| Guide | Covers |
| --- | --- |
| [Colour](./color/README.md) | Colour theory, palette building, the 60-30-10 split, tokens, print vs screen |
| [Typography](./typography/README.md) | Hierarchy, type scales, pairing, line length, numerals |
| [Grid and layout](./grid-and-layout/README.md) | Column grids for screen, print, social and slides, alignment, visual hierarchy |
| [Spacing](./spacing/README.md) | The 8px scale, proximity, density per style |
| [Accessibility](./accessibility/README.md) | Contrast, readability, focus, motion, alt text, the checks this repo runs |
| [Arabic and RTL](./arabic-and-rtl/README.md) | Arabic typography, right-to-left layout, Arabic–English pairing, bidi text |
| [Iconography](./iconography/README.md) | Icon grid, stroke, sizing, mirroring, per-style icon treatment |
| [Imagery](./imagery/README.md) | Photo briefs, cropping, retouching, licensing, alt text |
| [Motion](./motion/README.md) | Duration and easing tokens, per-style motion, reduced motion, video |

Each guide ends with a short checklist you can paste into a review.
