# Client reports

## 1. Structure

| # | Section | Contents |
| --- | --- | --- |
| 1 | Summary | Three to five headline results and what they mean, on one slide |
| 2 | Against goals | KPIs vs targets, with status (on track, at risk, behind) shown by text and icon, not colour alone |
| 3 | Channel detail | One slide per channel: the result, the reason, the action |
| 4 | Best work | Top creative with its numbers |
| 5 | Learnings | What we will change |
| 6 | Next period | Plan and requests |

## 2. Charts

| Question | Chart |
| --- | --- |
| Change over time | Line chart |
| Compare categories | Horizontal bar chart, sorted |
| Part of a whole (2–4 parts) | Stacked bar; avoid pie charts with many slices |
| One key number | Big number with comparison ("18 min, down from 31") |

- Label lines and bars directly; avoid legends when possible.
- Start bar charts at zero.
- One highlight colour for the point that matters (Swiss Precision: one red
  data point; Clinical Clarity: Care Teal with direct labels).
- Every number has a source and date range.

## 3. Consistency

Use the same template every period so clients can compare reports. Put the
reporting period on every slide footer.

## Checklist

- [ ] Summary on the first content slide
- [ ] Status by text and icon, not colour alone
- [ ] Charts labelled directly, sourced and dated
- [ ] Same template as last period
