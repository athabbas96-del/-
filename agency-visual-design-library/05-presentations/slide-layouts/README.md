# Slide layouts

## 1. Canvas and grid

- 16:9, 1920 × 1080 (13.33 × 7.5 in in PowerPoint).
- 12 columns, 40px gutter, 120px side margins, 96px top and bottom.
- Title position fixed on every content layout.
- Footer: client or project name, slide number, and "Sample data" or the data
  source where relevant. The library's content slides carry "Sample data".

## 2. Master layouts every template needs

| Layout | Use |
| --- | --- |
| Cover | Title, subtitle, date, logo |
| Section divider | Section number and title; full-bleed image or colour |
| Title + body | Text slide |
| Title + key figure + points | Results; rendered on every style page |
| Two columns | Compare, before/after |
| Full-bleed image + caption | Pace, emotion |
| Image grid | Work, moodboards |
| Chart | One chart, action title |
| Quote | Testimonial, pull quote |
| Team | Photos, names, roles |
| Closing | Next steps, contact |

## 3. Style in a deck

| Style | Deck behaviour |
| --- | --- |
| Quiet Luxury | One idea per slide, light display weight, stills between sections |
| Swiss Precision | Numbered slides (2.1, 2.2), conclusion titles, one red data point |
| Neo-Brutalism | Outlined cards with hard shadow, stickers flag takeaways |
| Organic Earth | Rounded image masks, ingredient photography, sentence-case titles |
| Future Tech | Dark slides, one glow field, live demos |
| Bold Editorial | Slides as spreads, pull quotes instead of bullets |
| Playful Pop | Colour-block slides rotating brand colours |
| Clinical Clarity | White slides, Mist panels, 24pt minimum |
| Modern Heritage | Arabic-first RTL slides, pattern bands at section openers |
| Kinetic Sport | Diagonal cuts, one huge stat, full-bleed action |

## 4. Building the template

- Build real masters in PowerPoint, Keynote or Google Slides (not pictures of
  layouts), with theme colours and fonts set, so content placed by others
  inherits the style.
- Provide fallback fonts if the brand fonts cannot be embedded.
- For bilingual decks, provide separate RTL masters; do not just right-align
  text on LTR masters.
