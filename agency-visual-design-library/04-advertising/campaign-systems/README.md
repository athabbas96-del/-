# Campaign systems

## 1. From idea to system

1. **Insight:** a true observation about the audience (creators lose files in
   group chats).
2. **Idea:** one sentence that dramatises it ("Group Chat Graveyard", for the
   fictional brand Klonk).
3. **Key visual:** the master execution that shows the idea in one frame.
4. **System:** rules that let the idea stretch to every format without losing it.
5. **Toolkit:** templates and specs for every channel.

## 3. Keeping it consistent

- The headline system: same length, structure and tone across formats.
- The visual device appears in every format, even the smallest banner.
- Logo and call to action in the same relative position.
- One campaign colour moment from the style's palette.

## 4. The toolkit to deliver

Key visual; layouts for each booked format; copy deck with approved headlines
and legal lines; image selects and licences; animation specs; templates for
local or social adaptation; a one-page campaign guide.

## Checklist

- [ ] Insight and idea written in one sentence each
- [ ] Key visual approved before adaptation
