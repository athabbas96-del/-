# Digital display

## 1. Core sizes (IAB standard units)

| Name | Size (px) | Notes |
| --- | --- | --- |
| Medium rectangle (MPU) | 300 × 250 | Most common; rendered on every style page |
| Leaderboard | 728 × 90 | Desktop top-of-page; rendered on every style page |
| Mobile banner | 320 × 50 | Very small: logo + 3–5 words + button |
| Half page | 300 × 600 | Room for image and story |
| Wide skyscraper | 160 × 600 | Stacked layout |
| Billboard (web) | 970 × 250 | Large desktop placement |

Always confirm sizes, file limits and click-tag requirements with the media
plan and the ad server. A 150KB initial load is a common limit for HTML5 and
image banners.

## 2. Layout

- Logo, message, button: all three must be visible in the final frame.
- The headline is the largest element; one line on leaderboards.
- The button looks like a button and says what happens ("Book online").
- A 1px border if the banner background is white or very light, so the ad's
  edge is visible on a white page.

## 3. Animation

- 15 seconds maximum total, usually three loops or fewer, then stop on the final frame.
- 3–4 frames: hook, message, proof, action.
- Follow the style's motion signature: hard cuts (Neo-Brutalism), spring
  bounce (Playful Pop), slow zoom (Quiet Luxury).
- No flashing more than three times per second.

## 4. After the click

The landing page repeats the banner's message and image
(see [Landing pages](../../03-websites/landing-pages/README.md)).

## Checklist

- [ ] All booked sizes produced; file weights within limits
- [ ] Logo, message and button visible in the end frame
- [ ] Animation 15s or less, loops limited, no flashing
- [ ] Click-through goes to a matching landing page
