# Print advertising and collateral

## 1. Common formats

| Item | Size |
| --- | --- |
| Magazine full page | Per publication, e.g. 210 × 280 mm trim with 3–5mm bleed |
| Newspaper ad | Per publication column grid |
| Flyer | A5 (148 × 210 mm) or DL (99 × 210 mm) |
| Poster | A2 (420 × 594 mm), A1 (594 × 841 mm) |
| Brochure | A4 or A5, folded or saddle-stitched (page count in multiples of 4) |

## 2. Production specification

- CMYK or spot colours, using the printer's profile; 300 dpi images at final size.
- 3mm bleed (or as specified); text at least 5mm inside the trim, more near binding.
- Print-ready PDF (PDF/X-4 or as specified), fonts embedded, crop marks.
- Black text set to 100% K and overprinted; large black areas as rich black per
  the printer's recipe.
- Avoid very thin type reversed out of colour, and text below 7pt.
- Ask for a hard proof for brand colours and photography.

## 3. Layout by style

- Bold Editorial and Swiss Precision translate most directly to print: column
  grids, strong type hierarchy.
- Organic Earth prints on uncoated or recycled stock; colours print duller, so proof.
- Modern Heritage uses foil or metallic ink for gold.
- Quiet Luxury relies on paper and finishes (letterpress, emboss) as much as ink.

## Checklist

- [ ] Publication or printer spec followed
- [ ] CMYK/spot, 300 dpi, bleed, safe margins
- [ ] Print-ready PDF with fonts embedded
- [ ] Hard proof for colour-critical work
