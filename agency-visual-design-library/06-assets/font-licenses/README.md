# Font licences

Every typeface the visual library loads or recommends is distributed through
Google Fonts under the **SIL Open Font License 1.1 (OFL)**.

**Verification:** each family's `license` field was read from its
`METADATA.pb` in the [google/fonts](https://github.com/google/fonts) repository
on 2026-10-12. Re-check before redistributing font files.

## What the OFL allows

- Free use in commercial work: print, web, video, logos, apps.
- Embedding in websites, PDFs, apps and documents.
- Modifying the fonts, provided modified versions are renamed (Reserved Font
  Names) and stay under the OFL.
- **Not allowed:** selling the font files on their own.

Logos made with OFL fonts may be trademarked; the font itself stays under the OFL.

## When a client brings their own fonts

Record the foundry, licence type (desktop, web, app, broadcast), number of
seats or page views, and who holds the licence. Commercial fonts are usually
licensed per use; a desktop licence does not cover web embedding.
