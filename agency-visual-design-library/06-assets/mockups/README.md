# Mockups

**Status:** no mockup files are committed yet. Photographic mockups (phones,
laptops, packaging, signage) are usually third-party files with their own
licences, and none have been licensed for this library.

## What exists today

The visual library renders flat mockups for every style in the browser:
browser window, social frames (1:1, 9:16, 4:5), billboard (2:1), MPU and
leaderboard, 16:9 slides, business cards and an A4 letterhead. Use these for
early presentations.

## What to add, and how

| Mockup | Formats | Notes |
| --- | --- | --- |
| Phone (portrait) | 1080 × 1920 screen | For stories, app screens, mobile web |
| Laptop / desktop | 1920 × 1080 screen | For websites and dashboards |
| Billboard in context | 48-sheet, 6-sheet | Day and night versions |
| Business card and stationery set | 85 × 55 mm, A4, DL | Paper texture visible |
| Packaging | Bottle, box, bag, cup | Match the styles' brand applications |
| Social profile grid | 3 × 3 grid | Instagram profile preview |

For each mockup file record: source, licence type and ID, licence holder,
allowed uses, and the date downloaded, in a `LICENSES.md` file in this folder.
Name files `mockup_subject_variant.ext` (for example `mockup_phone_hand-dark.psd`).
